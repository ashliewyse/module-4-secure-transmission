# One-minute demonstration plan

Install the dependency before recording. Open the terminal in the project folder
and increase the text size so the hashes and result are readable.

1. **0-10 seconds:** Introduce the purpose: a message is hashed, encrypted,
   decrypted, and checked for integrity.
2. **10-20 seconds:** Run `.\.venv\Scripts\python.exe secure_message.py` and type
   a short practice message such as `Hello from my Module 4 midterm!`.
3. **20-35 seconds:** Point to the original SHA-256 hash and encrypted content.
   Explain that AES uses the same secret key for encryption and decryption.
4. **35-50 seconds:** Point to the recovered message, recovered hash, and PASS
   result. Explain that the hashes match.
5. **50-60 seconds:** Mention that the key is generated randomly, stays in memory,
   and that the README explains confidentiality, integrity, and availability.

Practice once before recording and describe the steps in your own words.
The optional `--demo --tamper` run can be shown if time permits, but the normal
encryption/decryption/hash-comparison demonstration is the priority.

After recording, save or upload the video using your course's accepted method.
Check that the instructor can open its link. Include the repository URL and
recording URL in your Canvas submission.
